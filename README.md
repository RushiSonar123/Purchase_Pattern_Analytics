## 📌 Overview

Shoplytics is a data analytics project focused on understanding customer shopping behavior.
The project involves data loading, cleaning, exploratory data analysis (EDA), SQL querying, and dashboard creation to generate actionable business insights.

---

## 📂 Dataset

The dataset contains customer purchase and behavioral data, including:

* Customer demographics
* Purchase frequency
* Product categories
* Payment methods
* Review ratings
